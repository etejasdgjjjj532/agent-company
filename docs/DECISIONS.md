# 決定記録

設計の途中でユーザーと決めたことの一覧です。

## 構成

| 項目 | 決定 |
|---|---|
| 言語 | TypeScript。実行時の依存はなし (Node 標準ライブラリのみ) |
| 形 | デスクトップアプリ (Electron)。バックエンドは同じプロセスで動く HTTP + SSE |
| 対応 OS | Windows / macOS / Linux |
| Root | 設定で選択式。既定は Claude Code |
| 秘書 | 設立前に相談する別のエージェント。Root とは別の役割 |
| 画面の用語 | 技術用語を既定にし、設定で「会社メタファー」に切り替え可能 |
| 画面の公開範囲 | 既定は 127.0.0.1 のみ。LAN 公開は明示的な許可が必要 |

## 組織

| 項目 | 決定 |
|---|---|
| 深さ・同時実行数 | プリセット 3 段階 (軽量 / 標準 / 大規模) と手動入力 |
| 規模の決め方 | 秘書がおすすめを出し、数字で上書きできる |
| 稼働中の増減 | 上限内は自動、超えるなら承認 |
| 兄弟間の通信 | Root が決める許可制 (未実装) |
| 失敗時 | 2 回まで再試行し、その後は親がユーザーに報告 |
| ユーザーの直接指示 | 子にも可。Root へ通知される |

## 安全

| 項目 | 決定 |
|---|---|
| 子の権限 | 自分の worktree 内のみ書き込み可、ネットワーク不可から始める |
| 統合 | Root が提案し、ユーザーが承認 |
| 予算 | 時間とトークン |
| 秘密情報 | 記録前に自動でマスク |
| 記録の置き場 | リポジトリの外のユーザー領域 |
| コスト表示 | 取れるものは実測、取れないものは「不明」 |
| デーモンが落ちたとき | 記録から状態を復元して再開できる。途中だったノードは停止扱いで、Root に通知される (自動のやり直しは未実装) |

## 開発

| 項目 | 決定 |
|---|---|
| ブランチ | 機能ごとにブランチと PR |
| Adapter のテスト | 偽物の CLI で自動テスト、本物は手動確認 |
| 依存 | 最小限。標準ライブラリを優先 |
| API 連携 | GPT 互換 API は opencode 経由。設定を簡単にする |

## 実機で確認したこと (Linux)

- Claude Code / Codex / OpenCode は、プロンプトを標準入力で渡せる。引数より安全で、Windows の cmd でも崩れにくい。
- Codex の workspace-write サンドボックスは worktree の .git 管理領域に書けないため、コミットは子ではなくオーケストレーターが行う。
- Codex は `--ignore-user-config` を付けると、ユーザー設定のプラグインを読まずトークンが半分以下になる。
- OpenCode は `{env:VAR}` を別プロセスで展開するため、環境変数経由の API キーが空になる。実行中だけ権限 600 の設定ファイルにキーを書き、終了時に消す。
- Gemini CLI は認証がなく、実機では未確認。
